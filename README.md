# 🗣️ User Forum App

A full-stack forum application where users can create, comment on, and like forum posts. Built using **Next.js 14 App Router**, **Prisma ORM**, and **SQLite/PostgreSQL** for database interactions.

---

## 📌 Features

- ✅ User Authentication (custom logic or token-based)
- ✅ Create, Read, Delete Forum Posts
- ✅ Comment on Forums
- ✅ Like Forums (one like per user per forum)
- ✅ Access control — users can delete only their own posts
- ✅ RESTful API routes with `app/api` handlers
- ✅ Server-side rendering and dynamic routing

---

## 🛠️ Tech Stack

- **Frontend:** Next.js 14 (App Router), TypeScript, TailwindCSS
- **Backend:** Node.js (API routes in `app/api`)
- **Database:** Prisma ORM with SQLite/PostgreSQL
- **Authentication:** Custom Middleware with Token-based Auth (can be swapped for NextAuth)
- **Deployment Ready:** Can be deployed to Vercel or any Node hosting
